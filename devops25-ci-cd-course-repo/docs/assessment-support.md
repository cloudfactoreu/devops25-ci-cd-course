# Bedömningsstöd

## G-nivå

Studenten kan:

- bygga en enkel CI/CD-kedja
- använda automatiserade tester
- visa build och deploymentflöde
- förklara grundläggande felhantering
- motivera centrala steg i kedjan

## VG-nivå

Studenten kan dessutom:

- självständigt motivera designval
- identifiera svagheter i sin lösning
- föreslå förbättringar av processkedjan
- resonera om risk, kvalitet och effektivisering
- visa förståelse för hur lösningen skulle utvecklas i en verklig miljö

# Dag 3: Testning i CI

## Varför

En lyckad build betyder inte att systemet fungerar. Tester skapar kontrollpunkter i leveranskedjan.

## Uppgift

1. Kör befintliga unit tests.
2. Lägg till ett eget test.
3. Skapa ett fel som testet fångar.
4. Resonera kring var testet bör ligga i pipelinen.

## Reflektion

- Vilken risk minskar testet?
- Vilka fel fångar testet inte?
- När bör pipelinen stoppa?

# Kursens röda tråd

Nyckelord: **VARFÖR**.

Vi arbetar med samma kedja genom hela kursen:

1. Commit
2. Build
3. Test
4. Artifact eller container image
5. Deploy
6. Verify
7. Rollback eller återställning

För varje steg ska studenten kunna svara på:

- Vilket problem löser steget?
- Vilken risk minskar steget?
- Vad händer om steget misslyckas?
- Vad händer om steget saknas?

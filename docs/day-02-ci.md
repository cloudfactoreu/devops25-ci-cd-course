# Dag 2: Continuous Integration

## Varför

CI finns för att team ska upptäcka integrationsproblem tidigt och ofta.

## Uppgift

1. Gör en liten ändring i koden.
2. Skapa en pipeline som kör build och tester.
3. Skapa ett avsiktligt fel.
4. Läs loggarna och förklara var felet uppstår.

## Reflektion

- Vad upptäckte pipelinen?
- Vad upptäckte den inte?
- Varför är snabb feedback värdefull?
